## Overview
This document outlines a comprehensive overview of how to manage user roles and permissions within the SAP/Palantir system. It provides an in-depth understanding of access control models, their importance, and ways to configure it effectively for data security and privacy.

## User Stories
1. As a System Administrator, I want to define roles with specific permissions so that users can be granted the right level of access they require without having unnecessary privileges.
2. As an End-User, I want to have my role automatically updated when I receive new or modified permissions within our system, without needing to log out and back in. 
3. As a System Administrator, I want to know who has what roles & permission so that we can manage them effectively.
4. As an End-User, I want to be able to request changes to my role if required.

## Technical Context 
SAP/Palantir uses a role-based access control model. It allows for granular control over data and system resources based on user roles within the organization. The permissions are defined in terms of capabilities that an entity (user, group or application) has to perform operations such as read, write, delete etc., on specific objects/data (e.g., documents, emails, reports).
