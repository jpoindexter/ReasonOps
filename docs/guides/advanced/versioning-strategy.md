# Versioning Strategy for SAP/Palantir

## Purpose
This document outlines the versioning strategy being used at SAP/Palantir. The goal is to provide a consistent and transparent approach to managing changes in our systems, ensuring smooth transition when updates are released. 

### User Stories
1. As a system administrator, I want to be able to track all versions of my software so that I can understand how it has evolved over time.
2. As a developer, I want to be aware of the latest version so that I can make any necessary updates.
3. As a user, I want to have control over when and how new versions are released, so that we maintain stability and usability for our users.

### Technical Context
We use GitHub as our primary source control system for all code, including the versioning strategy. We also utilize semantic versioning, which involves incrementing the version number based on the type of changes made.
